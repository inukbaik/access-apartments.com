# Accessible Spaces (HackPrinceton Fall 2026)

An AI agent that screens Houston and LA listings for wheelchair accessibility using CoStar, Matterport and Vexcel data, plus Meta Ray-Ban glasses that guide you through a building's Matterport digital twin.
